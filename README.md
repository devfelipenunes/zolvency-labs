# Zolvency Labs — V0.11 Cinematic Universe (experimental)

Seven-act native-scroll experience. Original procedural models and real GLB assets generated from reproducible blueprints; no external downloaded model or Blender work claimed. Processor and cryostat imported via GLTFLoader; ledger articulated in Three.js from the same model blueprint. GLB ledger export is the assembled editing/reference version.

Node 22.12+, npm install, npm run dev. npm run build generates the models in public/models and builds Vite. npm test; npx playwright install chromium; npm run test:browser. Models are original conceptual visualizations, not physical/cryptographic/protocol simulations. Fallback: ?renderer=canvas. All movement uses scroll, no scroll lock. Preview remains noindex; final identity, physical GPU validation and commercial hosting approval remain pending.
