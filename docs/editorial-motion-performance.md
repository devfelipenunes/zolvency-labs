Base main a7313729 (V0.30). Founder reports unclear low-quality text, rapid scroll segments and sluggish rendering. Independent candidate, no public default changed. Use local/preview /?experience=editorial&profile=balanced (desktop), economy, cinematic. Without flag, released narrative, camera mapping and renderer remain controls. Other open PRs #122–125 must be reconciled before release; do not overwrite their changes.

## Implemented candidate
- Seven-act editorial copy in editorialStory.js, separate current Stellar focus from research directions. No product, partner or certification claims. Native HTML headline/body, shot-specific layout and high-contrast local surface; original extruded SVG brand only. Removes geometry generation and visibility-ray tests for non-brand text in this mode; no extra production font package. Native CSS text is independent of the 3D buffer scale. The HTML layout is shot-authored screen-space, not a projected world anchor; artistic review required.
- Camera pacing uses monotone inverse cumulative weighted distance from 400 samples per act. Increment = spatial metres/3 + angle degrees/65 + FOV degrees/35; skip almost-fully covered cut transitions (mask >= .98); positive reading floor and neighboring-cost smoothing. Existing geometry/path/holds preserved. Chapter min heights proportional to cost, 1.6–4.5 viewport heights, final additional viewport for scroll travel. Initial estimates ~19.37 desktop/~19.41 mobile scroll heights versus ~11.3/~9.8 previous. Cost map uses authored optical fallback, not actual geometry-dependent wallCut endpoint. Longer tour is a trade-off; validate user preference.
- Single render queue drives motion easing, max .65 normalized progress/second, time-based and reversible, no >.12 snap during normal wheel/touch; explicit Home/End, initial/restoration and resize may snap. Scroll read RAF remains (passive listener); cached DOM anchors, React state changes by chapter in candidate, no separate Stage smoothing RAF. Reduced motion and Canvas2D remain.
- Economy direct renderer, no composer targets or native MSAA, 512 shadow map desktop, initial .75 scale; balanced no offscreen MSAA, SMAA, adaptive AO candidate; cinematic retains supported 2x MSAA + SMAA and full postprocessing. Mobile uses direct path as before, economy caps scale further. Existing resolution governor and GPU timer retained. Physical hardware required to pick default.
- CPU phase timings (pose, scene, text, render submission) plus active frame interval, unique available GPU samples, draw calls, triangles, scale. Six software Chromium comparisons; report stalls, not claim hardware FPS.
- SDF/MSDF/HTML isolated audition: same local DejaVu Sans TTF, pinned msdf-bmfont-xml 2.8.0 installed only in separate CI, SDF red channel vs MSDF median shader with derivative smoothing, three sizes (14/20/32 CSS px), three buffer ratios (.6/1/1.5); 27 captures planned. No production atlas or package. Troika is alternative runtime SDF library, not benchmarked here. See https://threejs.org/manual/pages/creating-text.html and https://protectwise.github.io/troika/troika-three-text/ and https://github.com/soimy/msdf-bmfont-xml.
