# V0.17 — Facility refinement
V0.16 evidence: 17 tests, six jobs, 28 desktop/11 mobile captures; peak 206204 triangles/160 draws desktop, 159340/100 mobile; sampled six-ray clearance minimum .303m, not a continuous guarantee. Actual screenshot problems: bright server enclosure dominates, racks not visible, disconnected PCB/GPU and fast U-turn. V0.17 changes: shape-preserving C1 Hermite path; attempt to enter through the actual front door and face rack aisle; slower turn in bridge; remove disconnected PCB/GPU/projector from active scene. Facility uses external geometry only. Real mesh BVH audit samples 481 points with closest-point distance (including moving doors); diagnostics not production render overhead. It is not a swept capsule proof. Shadows from selected equipment, retained source PBR, restrained lighting and existing screen materials receive conceptual 2D Zolvency network/policy textures. Progressive two-slot loads after hangar; secondary failures keep available scene; resize CPU-submission heuristic is not measured GPU FPS. Optional desktop ?quality=cinema adds GTAO and subtle threshold bloom. New CC0 HDRI, panel, cable and LOD2 are acquired in isolated job and only added to stage after manifest review. Mobile LOD selection is on initial load, not dynamic by distance. No fabricated sound, no baked lightmaps until UV audit. Keep source models pinned; no TinyFish, new project or cost.
